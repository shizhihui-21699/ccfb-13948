# 门禁固件关键判断逻辑加固 + 故障注入仿真

针对电压毛刺(voltage glitching)攻击:攻击者在密钥比对瞬间干扰芯片,
使指令被跳过或寄存器比特被翻转,把"拒绝"翻成"放行"。

## 组成

```
firmware/
  door.h           固件与仿真器共享的常量(内存映射、门磁值、令牌常量)
  auth_naive.c     未加固对照固件(典型 memcmp 式判断)
  auth_hardened.c  加固固件(本项目交付物)
tools/
  rvm.c            ARMv7 指令集模拟器 + 故障注入仿真器
  link.ld          链接脚本(text@0x0, data@0x10000000)
  build.sh         一键构建
```

## 目标指令集与构建

目标指令集选 **ARMv7-A(ARM 态,定长 32 位指令)**:简单规整、clang 直接
支持、适合逐条建模。固件用 C 编写,clang 交叉编译,lld 链接为 ELF32;
仿真器 `rvm` 在电脑上解释执行,无需真实硬件。

```sh
cd tools && ./build.sh
./rvm hardened.elf --mode=all        # 全部注入战役
./rvm hardened.elf --mode=functional # 仅功能测试
./rvm naive.elf     --mode=skip1     # 对照组
./rvm hardened.elf --trace=50        # 指令级跟踪(调试用)
```

## 故障模型(与仿真器一致)

1. **单指令跳过**(skip1):枚举 .text 每一条指令,将其 NOP 化;
2. **双指令跳过**(skip2):枚举所有指令对,同时 NOP 化;
   —— 跳过按"每次取指命中都生效"建模,覆盖循环内指令的任意一次执行,从严;
3. **单比特翻转**(flip1):枚举 (执行步数 × r0–r14 × 32 比特) 以及
   CPSR 的 N/Z/C/V,在指定指令步前翻转指定寄存器的一个比特。

门锁建模:写 `DOOR_ARM` 后紧接着写 `DOOR_OPEN` 才算开门(锁存);
其他写入解除 armed。超时 / 非法访存 / 未实现指令一律按"未放行"计(安全侧)。
每次注入用 5 种错误密钥(全零、全 1、差 1 比特、差 1 字节、随机)分别测试。

## 加固手段(组合)

1. **默认拒绝**:所有状态初始化为拒绝,开门必须主动完整构造证据;
2. **四路独立比对**:前向异或 / 反向旋转 / 逐字节计数 / 再次前向,
   指令序列互不相同,单次跳过无法同时废掉多路;
3. **无分支掩码累积**:比对结果经 0/-1 掩码并入令牌,不给"跳过分支"留目标;
4. **魔法值令牌**:GRANT 与一切中间态汉明距离 ≥ 2(仿真器启动时自检常量),
   单比特翻转无法把拒绝令牌翻成放行令牌;
5. **参考密钥完整性校验**:密钥与其取反副本同存,逐字节验证 `b1^b2==0xFF`,
   防止密钥指针被翻转指向全零内存后"假密钥比真卡";
6. **三证据联合判定**:token、token2、步进计数器 guard 必须同时精确匹配;
7. **开门值由证据位流直接算出**:不存在单比特布尔开关;锁值与开门值
   汉明距离 32,单比特翻转无法把锁值变成开门值;
8. **执行机构 ARM→FIRE 双写状态机**:跳过任何一条写操作都无法开门;
9. **编译屏障**:防止冗余检查被编译器优化掉(`asm volatile`)。

## 实测结果(ARMv7,-Os)

| 指标 | naive | hardened |
|---|---|---|
| 代码体积 | 120 B / 30 条指令 | 408 B / 102 条指令 |
| 无故障周期(错误卡) | 79 | 374 |
| skip1 误放行 | **18 / 150** | **0 / 510** |
| skip2 误放行 | **271 / 2175** | **0 / 25755** |
| flip1 误放行 | **187 / 191180** | **0 / 905080** |

加固代价:体积 ×3.4、耗时 ×4.7(绝对值仍极小:408 B / 374 周期),
功能测试正确卡放行、错误卡拒绝全部通过。

## 已验证的攻击路径(加固迭代记录)

仿真器驱动的加固迭代,每一轮都由注入结果说话:

1. **初版加固**:skip1/skip2 已为 0,但 flip1 发现 69 种误放行——
   全部是把参考密钥指针(r12)单比特翻转指向全零内存,
   全零攻击卡与"假密钥"比对通过;
2. **加入密钥取反副本完整性校验**后,三类注入全部归零。

## 边界与说明

- 故障模型覆盖:单/双指令跳过、单寄存器比特翻转(含 CPSR 标志位)。
  未建模:三指令及以上跳过、双比特翻转、存储器(Flash/RAM)比特翻转、
  指令本身比特翻转——这些可在此框架上直接扩展;
- 跳过注入按"每次命中都跳过"从严建模,实际攻击者只能选一次执行,
  因此真实可利用性只会更低;
- 仿真器对未实现指令/非法访存按安全侧计,不会把异常误判为误放行;
- 常量安全性(令牌子集距离、拒绝态与危险值的距离、门磁值距离)
  由 `rvm` 每次启动时自检,改常量后会自动报警。
